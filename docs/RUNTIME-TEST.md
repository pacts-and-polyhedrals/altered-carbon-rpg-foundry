# First live Foundry v14 runtime test

After the system installs successfully:

1. Create a new world using **Altered Carbon RPG — Unofficial**.
2. Launch the world with no third-party modules enabled.
3. Open browser developer tools and confirm there are no red errors from `altered-carbon-rpg` during `init` or `ready`.
4. Create one Character actor, one NPC actor, and one Vehicle actor.
5. Open each Actor sheet.
6. Create a Skill, Sleeve, Weapon, Armour, Equipment, Trait, Condition, and Relationship item.
7. Roll a Skill from the Actor sheet.
8. Open the Character Creator and Rules Reference menus.
9. Create a Combat encounter and open the Altered Carbon Combat Console.
10. Test a weapon use, damage card, Wounds/Health mutation, and resleeving workflow.
11. Join from a second non-GM user and confirm sheet permissions, chat cards, targeting, and socket behaviour.

If any step fails, capture the first Altered Carbon-related console error plus the Foundry build number.
